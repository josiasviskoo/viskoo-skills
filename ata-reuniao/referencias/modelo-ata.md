# Modelo de ATA de reunião (estrutura aprovada pela agência)

## Estrutura

```
ATA DE REUNIÃO
────────────────────────────────────
Data:           [DD/MM/AAAA]
Cliente:        [Nome do cliente]
Participantes:  [o dono da agência + quem mais participou]
Tipo:           [ ] Acompanhamento  [ ] Briefing  [ ] Comercial

1. CONTEXTO
[Breve resumo do que motivou a reunião]

2. O QUE FOI DISCUTIDO
→ [Ponto 1]
→ [Ponto 2]
→ [Ponto 3]

3. DECISÕES TOMADAS
→ [Decisão 1]
→ [Decisão 2]

4. TAREFAS DA AGÊNCIA
→ [O que o dono da agência vai fazer], prazo: [data]
→ [O que o dono da agência vai fazer], prazo: [data]

5. TAREFAS DO CLIENTE
→ [O que o cliente vai fazer], prazo: [data]
(registrado na ATA; na plataforma vem desmarcado na conferência das tarefas)

6. PRÓXIMOS PASSOS
→ Próxima reunião: [data/hora ou "a agendar"]
→ [Outro encaminhamento]

7. NOVA DEMANDA / UPSELL
→ [Surgiu? Descreva] ou "Nenhuma nesta reunião"
```
